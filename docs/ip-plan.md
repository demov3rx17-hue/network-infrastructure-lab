# План IP-адресов

| Сеть | Адреса | Назначение |
| --- | --- | --- |
| VMnet8 | DHCP от VMware | WAN для VyOS |
| VMnet10 | только trunk | связь VyOS и Open vSwitch |
| VLAN 10 | `192.168.10.0/24` | Office |
| VLAN 20 | `192.168.20.0/24` | Servers |
| VLAN 30 | `192.168.30.0/24` | Guest |
| VLAN 40 | `192.168.40.0/24` | Management |

## Адреса на VyOS

| Интерфейс | Адрес |
| --- | --- |
| `eth0` | DHCP через VMnet8 |
| `eth1.10` | `192.168.10.1/24` |
| `eth1.20` | `192.168.20.1/24` |
| `eth1.30` | `192.168.30.1/24` |
| `eth1.40` | `192.168.40.1/24` |

## DHCP

| VLAN | Диапазон DHCP |
| --- | --- |
| 10 | `192.168.10.100` - `192.168.10.200` |
| 30 | `192.168.30.100` - `192.168.30.200` |
| 40 | `192.168.40.100` - `192.168.40.150` |

`server01` использует статический адрес `192.168.20.10/24`, шлюз `192.168.20.1`.
